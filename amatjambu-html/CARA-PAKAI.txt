CARA PAKAI WEBSITE AMATJAMBU (VERSI HTML)
==========================================

Isi folder:
  index.html   -> struktur halaman
  style.css    -> warna, ukuran, animasi
  script.js    -> isi website (nama, bio, video, medsos) + mesin animasi
  media/       -> semua foto, video, lagu

CARA BUKA
1. Buka folder ini di Visual Studio Code (File > Open Folder).
2. Klik kanan index.html > "Open with Live Server"
   (install extension "Live Server" dulu di VS Code), atau klik dua kali index.html.
   Catatan: video & lagu paling lancar dibuka pakai Live Server.

GANTI ISI (semua di bagian DATA paling atas script.js)
- Nama, bio, tulisan berganti (titles), teks tentang (about)
- Medsos: ganti handle & url ("#") dengan link akunmu
- Judul & cerita video
- Judul lagu

GANTI FOTO / VIDEO / LAGU (taruh di folder media/, nama file harus sama)
- Foto profil ............ media/avatar.jpg
- Banner hitam-putih ..... media/banner-1.jpg ... banner-4.jpg
- Foto galeri ............ media/foto-1.jpg ... foto-24.jpg
                           (mau lebih? tambah foto-25.jpg dst lalu ubah photoCount di script.js)
- Video .................. media/video-1.mp4, video-2.mp4, video-3.mp4
- Lagu ................... media/lagu.mp3

GANTI WARNA
- Buka style.css, bagian paling atas (:root = tema terang, html.dark = tema gelap).
- Ubah --fire untuk warna oranye utama.
